title: Home Server / NAS
description: In an effort to streamline my file access across devices, access my home network remotely, and explore networking and systems, I recently built a personal Network Attached Storage (NAS) home server using TrueNAS as an operating system. I repurposed components from an older computer, combined newer SSDs and HDDs, and configured the server to host cloud storage with file managers and media libraries. As well, I integrated TailScale to create a personal VPN using my personal devices to form a mesh. This allows me to use the server as an exit node when working remotely, efficiently routing my traffic securely through my home network. This has opened a world of productivity and I'm actively implementing more functionalities as I explore server hardware, networked storage, and system administration more.
